1. Interest‑Only Payment Logic
- When the user selects “Interest Only Payment,” repayment must be 0.

- The payment record must show:
  previousBalance
  interest
  repayment = 0
  totalCollected = interest
  newBalance = previousBalance (unchanged)

- When checked:
  - Disable or hide the repayment input.
  - Automatically set repayment = 0.
  - Automatically calculate interest based on:
      interest = currentBalance × interestRate
  - Display the computed interest amount before submitting.

Each interest‑only payment must be saved as:
{
  id: unique ID,
  date: selectedDate,
  previousBalance: borrower.currentBalance,
  interest: computedInterest,
  repayment: 0,
  totalCollected: computedInterest,
  newBalance: borrower.currentBalance,
  type: "interest-only"
}

  “Interest‑Only Payment for [Month] [Day], [Year]”
- Example display:
  “Interest‑Only Payment (May 21, 2026): Paid MOP 500 interest, principal unchanged.”

- Save interest‑only payments the same way as regular payments.
- Do not modify borrower.currentBalance unless repayment > 0.
- Ensure the payment history shows the correct date and type.

6. UI Requirements
- Add a checkbox or toggle labeled “Interest Only.”
- When enabled:
  - Hide or disable the repayment field.
  - Show the interest amount clearly.
- When disabled:
  - Show the repayment field normally.
